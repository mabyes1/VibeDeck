用 HTTPS 開啟 VibeDeck

長亮、主畫面 App 與穩定串流需要 HTTPS。第一次開啟會看到瀏覽器警告，不必安裝憑證。

  1. 按下「開啟 HTTPS」
  2. 若瀏覽器顯示警告，按「顯示詳細資訊」或「進階」
  3. 選擇「造訪此網站」或「繼續前往」，再回 VibeDeck 配對

            HACKABLE DECKS

            Create your own Deck

            一個 Deck 就是一個資料夾裡的普通網頁。VibeDeck 會直接交給裝置自己的 Browser viewport 原生渲染。

            1. 到 Deck 資料夾建立新資料夾，例如 my-deck
            2. 放入 deck.json
            3. 放入 index.html 與你需要的 CSS / JS
            4. VibeDeck 會自動偵測並把它加到上方導航
            {
  "name": "My Deck",
  "entry": "index.html",
  "icon": "✨"
}
            Deck folder C:\ProgramData\VibeDeck\Decks

            Static Deck 會在 sandbox="allow-scripts" 的隔離 iframe 中執行，因此不是 VibeDeck 主頁的同源腳本，也不能直接讀取受保護的 Host API。需要 Host 資料時，請使用文件中的 read-only Deck Bridge；不要把密碼、Token、憑證或其他 secrets 放進 Deck。
