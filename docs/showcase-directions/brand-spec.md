# VibeDeck showcase brand spec

## Source of truth

- Product: VibeDeck
- Core promise: Give your spare screen a new job.
- Product truth: a Windows Host that turns a browser-capable spare screen into either a real Windows display or a browser-native Deck.

## Visual guardrails

- Real product captures are the hero. Do not redraw or fake the UI.
- Do not use generic cyan/purple SaaS glow.
- Do not turn every block into a rounded card.
- No decorative emoji icons.
- Keep copy terse and product-specific.
- Every direction must visibly contain the same product truth; only the visual interpretation changes.
